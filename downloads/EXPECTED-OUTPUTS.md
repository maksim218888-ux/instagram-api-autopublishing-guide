# Что должно получиться

## После `check`

JSON показывает `ok`, SHA-256 файла, технические параметры, каждую проверку и будущий план. Важная строка: `live_action:false`. Подписанная часть временной ссылки скрыта.

## После `plan`

Появляется `approval-plan.json`, а в терминале — один `approval_hash`. Запросов на публикацию ещё нет.

## После `publish`

Только после явного подтверждения и разблокировки live-режима агент возвращает:
- `ok:true`;
- утверждённый hash;
- media ID и permalink;
- @username, подпись, тип и время, если выбранный API-маршрут отдаёт эти поля;
- `revoke_temporary_asset_now:true`.

## Что остаётся в журнале

Никаких токенов и подписанных URL. Нужны только: approval hash, account ID/@username, container ID, media ID, состояния, время событий, permalink и причина остановки.

## Как выглядит отчёт человеку

```text
Опубликовано один раз.
Аккаунт: @username
Режим: NORMAL / TRIAL MANUAL
Материал: <короткое имя> · SHA-256 <первые 12 символов>
Instagram: <permalink>
Media ID: <id>
Подпись: совпала / требует проверки
Временный доступ: закрыт
Журнал: <path>
Ограничения: <если есть>
```
