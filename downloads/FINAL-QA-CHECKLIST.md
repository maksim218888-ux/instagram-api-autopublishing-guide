# Финальная проверка

## До создания контейнера
- [ ] Аккаунт Business или Creator.
- [ ] Route, host, token type и permissions относятся к одной схеме входа.
- [ ] @username прочитан из API и совпал.
- [ ] Утверждены media, caption, cover и все флаги.
- [ ] Media preflight: PASS.
- [ ] Meta скачивает HTTPS-файл, SHA-256 совпадает.
- [ ] Подписанный URL не попал в журнал.
- [ ] Текущий publishing limit прочитан.
- [ ] План заморожен.
- [ ] Владелец подтвердил точный `approval_hash`.

## Во время публикации
- [ ] Создан один container.
- [ ] Container ID записан.
- [ ] Статус дошёл до `FINISHED`.
- [ ] `media_publish` вызван один раз.
- [ ] Неясный ответ не вызвал слепой повтор.

## После публикации
- [ ] Прочитаны media ID, permalink, @username, тип и время.
- [ ] Подпись и режим сверены.
- [ ] Временная ссылка закрыта.
- [ ] Журнал полный и без секретов.
- [ ] Владелец получил короткий отчёт понятным языком.

## Если есть очередь
- [ ] UTC и исходный часовой пояс сохранены.
- [ ] `approval_hash` уникален.
- [ ] Один worker держит lease.
- [ ] Автоповторы заканчиваются до publish boundary.
- [ ] Проверены alert и dead-letter path.

## Это ещё не PASS
- «App Review, скорее всего, пройдёт».
- «Trial, наверное, доступен».
- Жёстко записанные 50 или 100 публикаций без runtime query.
- Жёстко записанные 10 или 20 элементов карусели без проверки target environment.
- Container ID без `FINISHED`.
- Ответ publish без readback.
